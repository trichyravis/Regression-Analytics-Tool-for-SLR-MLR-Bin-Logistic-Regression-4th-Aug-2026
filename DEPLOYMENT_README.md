# Regression Analytics Laboratory

Upload these three files to the same GitHub repository folder:

1. `app.py`
2. `regression-practice-dataset-100.xlsx`
3. `requirements.txt`

In Streamlit Community Cloud, set the main file path to `app.py` and reboot the app.

The correct version displays:

- `How to Use This Tool` and `Educational Tool` tabs before analysis.
- A `Dataset source` choice in the sidebar.
- A built-in 100-customer practice dataset.
- An optional upload-your-own-data workflow.

If the sidebar immediately displays only `Upload Excel or CSV`, Streamlit is still running an older script. Confirm that the main file path is `app.py`, clear the app cache, and reboot.
